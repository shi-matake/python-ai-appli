# ✍️ AIライティングツール

Python + Streamlit + Gemini API で作った、個人用のAIライティングツールです。

## 機能

| ツール | 内容 |
| --- | --- |
| 📝 ブログ記事作成 | テーマ・読者・キーワード・文字数から見出し付き記事を執筆 |
| ✉️ メール返信作成 | 受信メールと返信方針から件名＋本文を作成 |
| 📄 文章要約 | 箇条書き／3行要約／レポート形式などで要約 |
| ✅ 校正・添削 | 修正後の全文と修正点の理由を提示 |
| 🔄 リライト・言い換え | 目的・文体を指定して複数案を作成 |
| 🌐 翻訳 | 意訳・直訳・ビジネス向けなどスタイル指定で翻訳 |
| 📣 SNS投稿作成 | X・Instagram などに合わせた投稿を複数パターン |
| 💡 タイトル・キャッチコピー | 切り口を変えたアイデアを大量提案 |
| 🧩 メモから文章化 | 箇条書きメモを報告書・議事録などに整形 |
| ✨ フリー入力 | 自由なプロンプトで実行 |

共通機能：ストリーミング表示、結果への追加修正指示、コピー用テキスト表示、Markdown保存、セッション内の履歴、モデル・temperature の切り替え

## セットアップ

```powershell
pip install -r requirements.txt
Copy-Item .env.example .env   # .env に GEMINI_API_KEY を記入
streamlit run app.py
```

APIキーは https://aistudio.google.com/apikey で取得できます（画面のサイドバーから直接入力することもできます）。

## ツールの追加方法

`tools.py` の `TOOLS` リストに `Tool(...)` を1つ追加し、プロンプトを組み立てる関数を書くだけで、画面に自動で反映されます。
